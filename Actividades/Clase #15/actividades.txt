actividad 3
Riesgo: Vulnerabilidad XSS (Cross-Site Scripting) por usar innerHTML con datos sin validar.
Corrección: Usar textContent o crear el elemento con createElement() y asignar el texto mediante textContent.
classList: Utilizar classList.add("invalido") para resaltar el campo cuando la entrada sea sospechosa y classList.remove("invalido") cuando sea válida.

const ul = document.querySelector("ul");
const fragment = document.createDocumentFragment();

for (let i = 1; i <= 200; i++) {
    const li = document.createElement("li");
    li.textContent = `Elemento ${i}`;
    fragment.appendChild(li);
}

ul.appendChild(fragment);
