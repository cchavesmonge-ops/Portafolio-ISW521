actividad - tema 3: Elementos y Flujo

blockquote - bloque - semántico - mostrar un cita larga de otra fuente en un articulo
span - en linea - presentacional - para aplicar estilos o clases a una parte especifica de algún texto
strong - en linea - semántico - indicar que un texto tiene importancia especial
article - bloque - semántico - para mostrar una noticia o publicación de otra fuente externa
b - en linea - presentacional - para resaltar visualmente texto sin indicar importancia semántica
time - en linea - semántico - para representar fechas y/o horas como la fecha de publicación de un articulo
ul - bloque - semántico - para listas no ordenadas como características o tareas
mark - en linea - semántico - para resaltar texto relevante como podría ser resultados de busqueda
code - en linea - semántico - mostrar fragmentos de código dentro de un texto
section - bloque - semántico - para dividir la pagina en secciones, como servicios, contacto y productos

actividad - tema 6: multimedia
¿que atributos del sandbox de iframe necesitas para que el mapa de google funcione correctamente?
	sandbox="allow-scripts allow-same-origin"
	permite ejecutar scripts y acceder a recursos del mismo origen necesarios para el funcionamiento del mapa

¿por que el video tiene 2 etiquetas <source> y no solo un src en el <video>?
	porque dependiendo el navegador soporta distintos formatos, si uno no es compatible el navegador intentara reproducir el siguiente

¿que pasa si omites el alt en la imagen?
	no hay una opción alterna para ver el contenido, ya sea visualmente, con un lector de pantalla y el usuario no tendría una descripción del contenido, incumpliendo así una buena practica del html
